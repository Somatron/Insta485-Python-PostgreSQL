# Insta485 (Followed from UoM course)

This project is based on University of Michigans EECS485 Web Systems that covers front and backend web systems and technologies, shoutout to the person that told me about this course.

Check it out on
 
https://insta485-javia.onrender.com

## (Made using Python & PostgreSQL)
I started this project to learn about how to make Flask API calls using Python, but most importantly how to use a monolithic database like PostgreSQL.

This project goes over User Authentication, Password hashing, File Uploads, Shell Scripting with Databases, and overall design of Insta485. It mostly copies features from the core Instagram you use everyday.
